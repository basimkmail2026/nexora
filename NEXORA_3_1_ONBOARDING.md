# Nexora 3.1 — Assistant Onboarding

- Public guided setup page: `/assistant-request` and `/nexora-test.html`
- Customer provides email, website, business profile, preferred assistant name, language and files.
- Customer receives a tracking token and can continue the same support conversation from the site.
- Staff can review and answer from Admin → Assistant Requests.
- Support replies are shown on the site and emailed when the customer selected email or both channels.
- Staff can set the final public key, embed code and activate the request.
